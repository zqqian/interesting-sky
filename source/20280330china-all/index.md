# **什么是月掩金星？**

简单的来说就是金星被我们的月亮给遮住了（月亮把金星挡在了后面），有没有发现有时候西方（或者东方）有颗很亮的星星？没错！那就是传说中的金星，想象一下如果月亮此时把金星慢慢的遮住，应该十分壮观。
