# **地球所见水星凌日**  

# **50万年之间**  

# **公元前25万年-公元25万年之间目录**  

* * *

  

*   **水星凌日**是一种天文现象。当水星运行至地球和太阳之间，如果三者能够连成直线，便会产生水星凌日现象。观测时会发现一黑色小圆点横向穿过太阳圆面，黑色小圆点就是水星的投影。
    
*   水星凌日目前发生在五月初或十一月初，十一月的凌日每间隔7、13或33年发生，而五月的凌日每间隔13或33年发生。平均每百年出现十三次水星凌日的现象,比金星凌日频繁。
    
*   发生于五月的凌日，因水星过远日点附近，所以在地球上看去视角直径约为12角秒；发生于十一月的凌日，因过近日点附近，所以仅约10角秒。
    
*   水星凌日按照[五月的降交点](http://eclipse.gsfc.nasa.gov/transit/image/TransitMercury09.GIF)和[十一月的升交点](http://eclipse.gsfc.nasa.gov/transit/image/TransitMercury08.GIF)划分为一系列的组，间隔16802天或46年。
    
*   **最近发生的水星凌日**：2003年5月7日、2006年11月8日、2016年5月9日。
    

公元前25万年-公元25万年，在这50万年之间地球上共发生96 179次水星凌日事件。**这些事件可分为3个类型**:：

> 水星过太阳表面【靠近中心】(C):  93 522次=  97.2 % 
> 
> 水星过太阳边缘(G)                        :   1 063次=   1.1 % 
> 
> 水星过太阳边缘【极点】(g)         :   1 594次=   1.7 %
