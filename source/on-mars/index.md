# **火星所见的流星雨**  

# **100年之间**  

# **公元1950年-公元2050年之间目录**  

* * *

  

**火星所见的流星雨**就是在火星上的天空中能看见的流星雨，由于火星具有一定的大气层，所以能够发生流星雨天文奇观。人类的探测器（如“好奇号”）可以看见。

![](http://interesting-sky.china-vo.org/wp-content/uploads/2014/06/82781402890811.jpg)

2004年3月7日[勇气号火星探测器](http://zh.wikipedia.org/wiki/%E5%8B%87%E6%B0%94%E5%8F%B7%E7%81%AB%E6%98%9F%E6%8E%A2%E6%B5%8B%E5%99%A8)可能拍摄到的火星天空中出现的流星，图片来源：[http://www.arm.ac.uk/~aac/mars/areosights.html](http://www.arm.ac.uk/~aac/mars/areosights.html)
