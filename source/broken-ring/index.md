## （最大食分时月球的[本影圆锥顶点](http://lifeng.lamost.org/czas/eclipse/images/3.jpg)相切地球表面的日食事件）

**断环日食**：就是日环食的最大食分地区的最大食带宽度近乎为0公里，持续日环食时间近乎为0秒。而从这一地区到两边走向的日食带就会越来越宽，看到日环食持续时间就会更长些。在这个最大食分的地区，理论会看到日全食和日环食的结合点（本影圆锥顶点相切地球表面瞬间），不过相当之短暂，不易肉眼察觉。

力学时 ：也指地球时，力学时与世界时之差值，2014年-2015年为69秒左右（其它年份点击这里），因此力学时+7小时58分钟51秒方可等于北京时间【力学时中的小时大于等于16时的需加1日】

时差Δ ：力学时与世界时之差值

朔望月数：自2000年1月6日新月开始，2000年2月05日的新月为第一个朔望月数，以此后推，前推为负。布朗朔望月数（第一个）是自1923年1月17日开始，换算为朔望月数为953个。

沙罗周期：是18年11天又8小时（大约6585日）的食的周期，可以用来预测太阳和月球的食。经过一个沙罗周期，太阳、地球和月球回到相似的几何对应位置上，于是将发生几乎相同的食。

日食类型:

 P  = Partial Eclipse.偏食

 A  = Annular Eclipse.环食

 T  = Total Eclipse.日全食

 H  = Hybrid or Annular/Total Eclipse.全环食

第二个字符的日食类型：

 "m" = Middle eclipse of Saros series.沙罗周期中间时间

 "n" = Central eclipse with no northern limit.有中心线无北界限线

 "s" = Central eclipse with no southern limit.有中心线无南界限线

 "+" = Non-central eclipse with no northern limit.无中心线无北界限线

 "-" = Non-central eclipse with no southern limit.无中心线无南界限线

 "2" = Hybrid path begins total and ends annular.全环食，开始是全食结束是环食

 "3" = Hybrid path begins annular and ends total.全环食，开始是环食结束是全食

 "b" = Saros series begins (first eclipse in series).沙罗周期的开始

 "e" = Saros series ends (last eclipse in series).沙罗周期的结束

伽马值 ：地球中心到食甚瞬间的本影锥中心轴的垂直距离。对于日食正号表示日食带划过地球以北区域，负号表示以南。单位：赤道半径为1个单位

食分 ：当时太阳的视直径（角度）被月球掩盖的百份比。注意月球掩盖太阳直径（角度）的百份比并不等于月球掩盖太阳面积的百份比。

纬度 ：最大食分的地理纬度

经度 ：最大食分的地理经度

高 ：最大食分的地理的太阳高度

位 ：最大食分的地理的太阳方位角

带宽 ：全食或环食最大食分的地理的最大食带宽度，单位：公里

持续时间：全食或环食最大食分的地理的持续时间，中心最大。单位：分（m）和秒（s）
